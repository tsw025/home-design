# Home design

Interactive 3D model of the Pannipitiya house, built from the architect's drawings CK/181 A-02 to A-06, with four roof options (A to D), a dimensions overlay and a night lighting mode.

Open `index.html` in a browser, or view it on GitHub Pages once Pages is turned on for this repo (Settings → Pages → Deploy from a branch → `main` / root).

Concept study only, not for construction.
